# 官方 XML 转换交接

1. 通过 final 后运行 `handoff`，新目录不得已有旧文件。
2. 使用 https://cponline.cnipa.gov.cn “工具下载”的当前官方转换工具及手册，或系统申请文件编辑功能。输入兼容性以工具当前手册为准，不承诺任何 DOCX 均能无损转换。
3. 交接包 review-docx 对应权利要求、说明书、摘要、说明书附图和单独摘要附图；figures 保存原图；content.json 是内部内容核对表，不能上传冒充XML。
4. 在官方预览逐字检查权项引用、数字单位、数学/化学式、表格和图片；无法正确转换时按官方编辑功能修复。变更内容须重新审查。
5. 申请人与全部自然人发明人身份、请求书各项、委托、优先权等按案件填写。外观设计确认产品名称、视图和简要说明；软件方案不能改实用新型类型规避审查。
6. 保存转换器版本、文件哈希、官方校验/预览记录；XML有正确信息和格式后申请人再签署提交并按通知缴费。

状态：draft → review_ready → official_conversion_pending → 官方校验及人工核对 → 实际提交回执。不能把某个本地 JSON 的 true 当作国知局通过。原始审查文件在 evidence 中留存；复制后的 source-NNN 便于核对，其原路径引用不会被静默改写。交接目录不是可直接再次执行 final 的案件工作目录。

## 转换源（DOCX）要清掉的项

《关于规范提交专利电子申请的指引》禁止域对象、文本框、自选图形等。handoff 拆出的文件应满足：

| 项 | 要求 | 为什么 |
| --- | --- | --- |
| 段落编号 `[0001]` | 不得出现 | XML 段号由系统生成。注意是**半角方括号**，用全角 `【】` 去匹配会误判成 0 条 |
| 页脚 `PAGE` 域 | 清空页脚 | 域对象属禁止项；XML 没有页脚概念，页码由系统按页生成 |
| 水印 / 宏 / 嵌入对象 / 超链接 / 控件 / 批注 / 修订 / 文本框 / 自选图形 / 浮动图 | 不得出现 | 同上 |
| 图片 | 300DPI JPG/TIF，图内无图号文字，「图1」以文字形式在图片外，单页内不跨页 | 转换器对图片格式与图号位置敏感 |
| 拆分遗留的孤儿图片 | 删除 | 非正文内容；**按 `document.xml.rels` 里实际被引用的 rId 判断，不能按文件名删**（按文件名删会连带删掉正文还在用的图） |

**「带页码的打印稿」与「能转 XML 的转换源」是两个目标**，不要指望同一份文件兼得：
前者要页脚页码（纸件规定），后者必须没有域对象。

## 100001~100004 模板不是电子表单

官方「表格下载 · 通用类」的 `100001权利要求书` / `100002说明书` / `100004说明书摘要`：
第 1 页只有页眉标识（如「权利要求书 / 100001 / 2023.03」，约 30 字）、**0 个表格**，
第 2 页是「注意事项」，并写明「首页用此页，续页可使用同样大小和质量相当的白纸」。

结论：它们是**纸件首页的版式基准**，不是填格子的电子表单。用户问「官方有模板，
我们直接写是不是错了」时，回答「版面照它、正文不必填进去」，并区分**表单类**文件
（110101 请求书、100006 补正书等，要逐栏填）。

注意别把两套「模板」混为一谈：WORD转XML编辑器页面提供的是**五书模板文件**（带转换器所需标记），
与纸件首页模板用途不同。

## 摘要附图：无独立编码（待确认，勿写成规则）

上传清单只有 100001~100004，没有「摘要附图」独立编码。实务做法是在请求书第 24 栏填
「指定说明书附图中的图__为摘要附图」，即**填图号**。该做法未在本次核查的官方文件中
直接读到，提交前向电子申请咨询/代办处确认。

## 已核实的官方操作入口

[WORD转XML编辑器及模板手册](https://cponline.cnipa.gov.cn/GzfwYwblGlwhTMVC/GzfwYwblGlwhT/selectToolsById?weihuRid=157)。2026-09-30核查页面显示 Windows 10及以上，最新安装包标为 V4.3_2_20251218（页面写更新日2025-12-18）；实际使用仍检查新版本。

官方五书模板操作说明给出的路径：在模板对应区域编辑/粘贴说明书摘要、摘要附图、权利要求书、说明书和说明书附图；用“专利处理→添加标记”；将光标放入一书内容中，再用“XML生成”生成对应文件。模板和转换器会添加自身所需标记。本项目不伪造这些专有标记，也不把普通Word当成已转换文件。

说明书内容区使用稿件真正技术正文，不复制本工具审查报告、证据ID和交接状态。按当前手册确认文书标题/页眉、段落标记、复杂对象及图片处理。通过官方XML预览逐项核对后才提交。
