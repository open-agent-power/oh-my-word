# Content support probe

This is a four-case known-case mechanism regression, not a benchmark or a holdout. SciFact claim 51 is already exposed and may only be used as a regression. It must not support generalization or a default-prompt upgrade claim.

Runtime CLI discovery uses `WORD_SKILLS_CODEX` when explicitly set, otherwise `codex` on PATH. Preparation records the actual executable hash/version and rejects a missing executable before creating a run directory. Offline unit tests provide a synthetic binary identity and stub version observation; they do not require or execute Codex. A separate portable version-command test runs Python's harmless `--version`, not a model call.

The paired conditions use the same case source, claim, model (`gpt-6-luna`), low reasoning effort, runtime flags, and short JSON schema. A is concise direct relation assessment. B adds explicit checks for subject, relation, polarity, population, time, and proposal status. There are two independent fresh CLI runs per case and condition: 4 × 2 × 2 = 16 planned calls. Jobs are shuffled with the frozen seed and capped at two concurrent processes. There are no quality retries. A missing resolved model stays `unknown`; a mismatch is recorded and is not retried.

Run `python -m evals.content_support.probe prepare --data-root <external support-probe directory> --run-id support-probe-v2` to extract the public source, write tasks and hidden expected labels, construct prompts and the shuffled plan, and hash all inputs. Preparation makes no model calls; it records the CLI binary SHA-256 and observed `codex --version`, and execution refuses a changed binary. After review and authorization, run `python -m evals.content_support.probe run --prepared <external support-probe\support-probe-v2> --execute`. Each call stores raw CLI trace, stderr, response, usage, and the observed resolved model; summary counts keep all 8 planned jobs per condition in the denominator. Model output is not factual proof; root must manually review all four expected labels and source quotations.

Cases 1–2 use SciFact claims 51 and 53 with the same public abstract (document 45638119) extracted from the frozen heldout candidate corpus. Case 3 is a host-derived male-population mismatch case; it has no original SciFact gold label. Case 4 uses a clearly marked host-authored synthetic proposal note. Full provenance and expected labels live in the external probe directory; expected labels are never copied into model workspaces.
