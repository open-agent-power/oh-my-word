# 专利写前阅读

核查于2026-10-24。按 [共用阅读规则](../../../shared/references/source-reading.md) 先确定本次申请类型、法域、阶段与技术领域，再读下表相关原文；不用每次通读全部手册。同案改措辞可复用已读记录，影响技术方案、范围或规则适用时补读。

| 本次问题 | 固定来源与章节 | 使用边界 |
| --- | --- | --- |
| 交底如何转成可支持的技术方案 | [WIPO 中文《专利撰写手册》第二版](https://www.wipo.int/edocs/pubdocs/zh/wipo-pub-867-23-zh-wipo-patent-drafting-manual.pdf)，第三单元1.1—1.3 | 学习获取和理解交底的方法；不能把公开范例当作本案发明，也不将发明人未提供的信息补成事实 |
| 权项组织、概括与支持 | 同手册第四单元及第六单元第10节；按本次问题选读 | 阅读原例及限制，检查范围能否由实施方式支持；通用教学不替代中国规则，不推断已有新颖性或可授权 |
| 说明书、附图和摘要如何联动 | 同手册第七单元，尤其第2节撰写顺序和第3节各部分写法 | 写作顺序是方法选择，非统一强制程序。结合 [本地写法](drafting-method.md) 与中国要求使用 |
| 中国申请的内容和支持要求 | [专利法](https://www.cnipa.gov.cn/art/2020/11/23/art_97_155167.html) 第26条、[2023实施细则](https://www.cnipa.gov.cn/art/2023/12/21/art_98_189197.html) 第20—26条；外观另核对相应条款与视图要求 | 实际读与任务有关的原文和适用例外；不把发明章节、海外格式或示例权项套用于外观 |
| AI/算法方案的披露与案例 | [指南修改决定84号](https://www.cnipa.gov.cn/art/2025/11/13/art_74_202560.html)，第二部分第九章6.3.1、6.3.3例20/21；创造性问题另读有关例子 | 决定明示2026年1月1日起施行。结合 [规则说明](cnipa-2026.md) 所列基础指南与适用修改；本页链接是修改决定，不是完整整合版。不能把个别案例扩大为所有案件必须给全部参数/实验 |
| 本案技术知识、对比方案与公开时间 | 原始交底、源码/实验、版本对应的官方技术文档；实际对比专利/论文/产品原文 | 技术背景资料与本案事实分开；按技术问题和时间进一步检索，不把固定阅读清单当作查新完整性保证 |

有规则变更或适用性疑问，限定 `site:cnipa.gov.cn`，带规则名、申请类型、主题和时间检索，打开原文核对。正式用途需检查当期适用依据；本次原文可读不表示以后一直有效。原文不可得时记录所用快照和缺口，不绕过原有正式交付检查。
