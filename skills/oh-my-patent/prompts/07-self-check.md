# 07 · 自检和交付

先执行 08 内容审查，再跑 lint。形式检查不是法律结论。

1. `python tools/patent.py lint 稿件.md`；修正 ERROR、核对 WARNING。
2. 修正引起内容或证据变更，重新执行 08，不复用旧哈希。
3. `build --final --facts TECH_FACTS.json --review content-review.json`；不得 --force。
4. 打开 Word 或渲染预览，核对编号、公式、表格、图片、分页与正文完整性。脚本结构测试不代表 WPS/Office 实际版面一致。无法渲染时如实记录，不能声称完成视觉验收。
5. **版面量化自检**（交付纸件/送审稿时逐项量，不能只看设定值）：

   | 项 | 合格判据 |
   | --- | --- |
   | 页码 | 各部分**分别**起号、页脚左右居中（版心不对称会整体偏右）；数值判据见 [版面硬规则](../references/cnipa-2026.md#版面硬规则) |
   | 字高 | 用默认字号；别为「好看」调大，实测值见 [实测结论](../../../docs/cnipa-format-lessons.md) |
   | 行距 | 用默认行距；不要调大，实测对照见 [实测结论](../../../docs/cnipa-format-lessons.md) |
   | 页边距 | 按默认页边距，只印正面（数值见 [版面硬规则](../references/cnipa-2026.md#版面硬规则)） |
   | 说明书首页 | 发明名称居中，名称与正文之间空一行，五部分标题齐全 |
   | 权项 | 每一项只在结尾用一个句号（分项段末用分号）；无插图；术语与说明书逐字一致 |

   墨迹字高与行间空白只能渲染后量（300dpi 位图扫行带），不能用字号或倍数折算。
   方法见 [CNIPA 版面与交付](../../../docs/cnipa-format-lessons.md)。
6. 用户要求申请准备时运行 handoff；按 references/cnipa-xml-handoff.md 完成官方转换、预览与请求书。工具未运行就标记 conversion_pending。
7. 交付稿件与审阅文件、证据、交接清单，说明尚需实际完成的步骤。缺技术材料时可以交草稿与待确认问题，不假装 final。
